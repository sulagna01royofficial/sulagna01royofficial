### 2. 🤖 Predictive Analytics: Students' Academic Performance
**Duration:** Jan 2026 - Jun 2026 | **Type:** M.Sc. Semester 2 Course Project

- **Multiple Linear Regression Model:** R² = **86.4%** ✅
